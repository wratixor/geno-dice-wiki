# Медитация

Практика сосредоточения восстанавливает Психику.

Основной: Самообладание; поддерживающий: Техника; вспомогательный: Тело.

## Обычный режим · I–III

Восстанавливает Психику тремя тактами. Такт, начавшийся при полной Психике, пытается добавить Импульс.

```text
Психика периодического восстановления сумма = 130.56 × [0.70 Q(Самообладание) + 0.30 Q(Техника)]; Тело/Дух смещение перераспределяет фиксированную сумму между 3 тактами
```

## Ульта · IV–VI

Избыточное лечение само по себе не превращается в Импульс. Перегрузка отдельно меняет один заряд Защиты на один Импульс.

```text
Психика периодического восстановления сумма = 324.75 × [0.70 Q(Самообладание) + 0.30 Q(Техника)]; то же перераспределение; эффекты Импульса полного такта и перегрузки сохраняются
```
