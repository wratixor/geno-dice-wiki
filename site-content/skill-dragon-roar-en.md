# Dragon Roar

Spirit creates a supernatural roar that pressures Psyche directly without turning Impulse into a barrier.

Primary: Spirit; Support: Onslaught; Auxiliary: Reaction.

## Normal · I–III

Supernatural direct Psyche damage.

```text
Psychic base = 187.68 × [0.70 Q(Spirit) + 0.30 Q(Onslaught) × E25(Reaction/Technique)]
```

## Ultimate · IV–VI

Ultimate punishes a target that was already prepared: bonuses for zero Impulse and low Psyche stack. Overload adds a bonus hit only when at least one setup condition was true before the action.

```text
Psychic base = 298.77 × [0.70 Q(Spirit) + 0.30 Q(Onslaught) × E25]; exposed/low/Overload bonuses scale with Q(Onslaught)×E30(Reaction/Technique)
```
