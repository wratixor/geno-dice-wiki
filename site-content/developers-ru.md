# Для разработчиков

Вики — это граф связанных точек. Git хранит корни и главную; сервер — аккаунты, пользовательские точки, подписки и обсуждения.

- Статическая копия: сборка `python3 build.py`, публикация `dist/`; собственную базу не запускает.
- Подключённая вики: вход и пользовательские действия обслуживает выбранный общий сервер.
- Независимый сервер: отдельные backend и PostgreSQL, собственные регистрации и влияние.

[Установка по режимам](https://node06.neocities.org/setup/) · [Код движка](https://github.com/wratixor/node06) · [Настройка сервера](https://github.com/wratixor/node06/blob/main/backend/README.md)

Для своих корней используйте публичный контентный репозиторий с `node06-roots.json`; связанный с сервером источник обновляет данные, а не запускает код из форка. Политику обновлений собственного форка выбирает его администратор.
