# Cleanse

Cleanse restores the damaged layer itself: bodily Curse returns Endurance, mental control returns Psyche, and mixed harm splits the same recovery budget.

Primary: Self Control; Support: Spirit; Auxiliary: Reaction.

## Normal · I–III

Curse route recovery to Endurance, mental/control negatives route it to Psyche, and a mixed set splits the same budget 50/50. No actual dispel means no immediate healing.

```text
Triggered recovery budget = 979.2 × [0.70 Q(Self-Control) + 0.30 Q(Spirit) × E25(Reaction/Technique)]; CLEANSE_GUARD ×1
```

## Ultimate · IV–VI

Protection charges block future negative effects and restore the resource attacked by the blocked status: Curse → Endurance, mental/control → Psyche.

```text
Triggered recovery budget = 1558.8 × [0.70 Q(Self-Control) + 0.30 Q(Spirit) × E25(Reaction/Technique)]; Ultimate/Overload guard riders unchanged
```
