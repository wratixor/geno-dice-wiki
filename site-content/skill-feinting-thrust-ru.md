# Обманный выпад

Ложный выпад провоцирует подготовленную защиту; настоящий удар использует открывшееся окно.

Основной: Техника; поддерживающий: Тело; вспомогательный: Натиск.

## Обычный режим · I–III

Против защищённой цели финт расходует один заряд Защиты, затем настоящий выпад обходит оставшиеся.

```text
Без Защиты = 79.56 × Q(Тело) × E30(Натиск/Самообладание); при Защите добавить 22.44 × Q(Техника)
```

## Ульта · IV–VI

Урон по защищённой цели выше урона по открытой. Перегрузка тратит свою Защиту и пытается снять ещё один заряд у цели; защитного эффекта исполнителю не даёт.

```text
Без Защиты = 125.386 × Q(Тело) × E30(Натиск/Самообладание); при Защите добавить 69.464 × Q(Техника); Перегрузка снимает 1 Защиту до урона
```
