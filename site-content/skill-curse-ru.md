# Проклятие

Проклятие истощает Выносливость и ослабляет её восстановление, но не дискретный набор Защиты.

Основной: Техника; поддерживающий: Натиск; вспомогательный: Дух.

## Обычный режим · I–III

Наносит начальный удар и периодический урон; на один раунд сильно подавляет восстановление Выносливости.

```text
Начальный физический урон = 89.76×Q(Натиск); периодического урона сумма = 97.92×Q(Техника); подавление лечения = нейтральное значение + 0.15×bias(Дух/Тело)
```

## Ульта · IV–VI

Перегрузка углубляет и продлевает подавление лечения, не умножая периодический урон ещё раз.

```text
Начальный физический урон = 168.87×Q(Натиск); периодического урона сумма = 207.84×Q(Техника); подавление лечения ульты/перегрузки использует нейтральную опору + 0.15×bias(Дух/Тело)
```
