# Каменный град

Магия создаёт отдельные физические камни; каждый из них взаимодействует с защитой самостоятельно.

Основной: Дух; поддерживающий: Натиск; вспомогательный: Реакция.

## Обычный режим · I–III

Тратит один Импульс и наносит два физических попадания.

```text
Цена 1 Импульс; PrimaryBudget = 2×74.256×Q(Дух); hit1=PrimaryBudget/2; hit2=hit1×E30(Реакция/Техника)
```

## Ульта · IV–VI

Сохраняет два основных попадания; перегрузка покупает третье, а не скрытый обход Защиты. Пошатывание связано с реальным прорывом серии через Защиту к Выносливости.

```text
Цена 1 Импульс; PrimaryBudget = 2×135.096×Q(Дух); hit1=PrimaryBudget/2; hit2=hit1×E30; Перегрузка hit3=135.096×Q(Натиск)×E30; эффект Пошатывания при пробитии сохраняется
```
