# Регенерация

Постепенное естественное восстановление тела.

Основной: Самообладание; поддерживающий: Тело; вспомогательный: Техника.

## Обычный режим · I–III

Восстанавливает Выносливость тремя тактами.

```text
Выносливость периодического восстановления сумма = 130.56 × [0.70 Q(Самообладание) + 0.30 Q(Тело)]; Техника/Реакция смещение перераспределяет фиксированную сумму между 3 тактами
```

## Ульта · IV–VI

Увеличивает суммарное восстановление; избыток не создаёт Защиту. Перегрузка переносит будущий такт вперёд, не увеличивая общую сумму.

```text
Выносливость периодического восстановления сумма = 389.7 × [0.70 Q(Самообладание) + 0.30 Q(Тело)]; то же перераспределение; Перегрузка переносит один будущий такт на текущий момент
```
