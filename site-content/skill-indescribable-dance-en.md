# Indescribable Dance

The indescribable ritual dance disrupts the opponent's preparation rhythm while buying the performer time to take Guard; it is tempo control, not an attack or magic.

Primary: Technique; Support: Onslaught; Auxiliary: Body.

## Normal · I–III

The dance disrupts the target's next positive Impulse gain, grants +1 Guard, and slightly exhausts the performer's Endurance; proper stats reduce that ritual cost. It is CONTROL, so it grants no generic Impulse.

```text
Guard +1; execution quality = 0.70 Q80(Technique) + 0.30 Q80(Onslaught) × E25(Body/Spirit); Endurance self-harm = decreasing DanceCurve(quality); disrupt next Impulse gain
```

## Ultimate · IV–VI

Stored Impulse remains spendable; only new gains are blocked for the rest of the current round. Overload strengthens the user's preparation without extending the control window.

```text
same stat-scaled self-harm; block new Impulse this round; Overload Guard rider unchanged
```
